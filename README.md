## Rest API
REST API is the modern way of communicating with the HTTP using different methods. The famous ones are- POST, GET, DELETE, PUT that are used to create, fetch, delete and update data with respect to the database used in the particular project. The project shows the use of this style. In short, this is also known as *CRUD* operation.

## Database
For database and dealing with data, we use MySQL. The details on the server can be found in *db_connection.py*. After we have ensured and verified the connection, we then do the CRUD operations as mentioned using raw SQL. 

## FastAPI
The reason for selecting FastAPI is because it is lightweight and can be scalable in the long run. Also, this is one of the popular frameworks used widely.
